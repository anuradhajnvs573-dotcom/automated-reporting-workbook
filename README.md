# 📊 Automated Reporting Workbook

## 📌 Project Overview

The Automated Reporting Workbook is an Excel-based data analysis and reporting project designed to transform raw sales data into meaningful reports and visual dashboards.

The project demonstrates how Excel tables, formulas, calculations, and charts can be combined to create an automated reporting solution.

## 🎯 Objectives

- Analyze sales transaction data
- Calculate important business KPIs
- Track monthly revenue and profit
- Compare regional performance
- Analyze product performance
- Analyze salesperson performance
- Present results through a professional dashboard

## 📊 Dashboard Features

The dashboard includes:

- Total Revenue
- Total Profit
- Total Orders
- Units Sold
- Monthly Revenue Trend
- Monthly Profit Trend
- Revenue by Region
- Revenue by Product
- Salesperson Performance
- Summary Reports

## 🗂️ Workbook Structure

### 1. Dashboard
Contains the main visual dashboard with KPIs, charts, and summaries.

### 2. Raw_Data
Contains the sales transaction dataset used for analysis.

### 3. Report_Data
Contains calculated KPIs and performance summaries.

### 4. README
Contains project documentation and instructions.
